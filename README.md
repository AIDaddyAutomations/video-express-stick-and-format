# Spokesperson & Stickman Story Documentary

Create clear, engaging stories with a photorealistic spokesperson speaking on camera, then continue that same voice over story-matched 2D stickman scenes. The format works for explainers, customer stories, and promotional videos.

## Quick start

1. Give a browser-capable agent the instructions in `SYSTEM_PROMPT.md` and access to the signed-in VideoExpress.ai session.
2. Supply a topic or story brief. Optionally specify spokesperson, voice, ratio (16:9 or 9:16), and total duration (up to five minutes). If the topic is supplied and preferences are omitted, use the defaults in the system prompt.
3. Let the agent research, plan, generate, assemble, save, and export the finished video in VideoExpress.

This is a browser workflow, not an executable or direct API integration. One selected voice is used for the spokesperson and the full narration. The spokesperson appears and speaks at the opening; their narration then carries across consistent 2D stickman scenes with costumes, settings, and actions suited to the story. Product claims should be grounded in supplied or verified information. No anime or watercolor scenes.
